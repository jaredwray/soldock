# Spike findings

Findings notes from spike tasks (`kind: spike`) and measurement-style tasks (dogfood reports, benchmarks, load results). Name each file `<task id>-<slug>.md`, for example `S00.T13-email-service.md`. A spike that settles a design question also writes or updates an ADR in [`../adr/`](../adr/). This folder holds the evidence, and the ADR holds the decision ([process §7](../process.md#7-spikes)).
