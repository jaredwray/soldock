# `dock` — the Worker

> Status: **skeleton** (S00.T04). Domain modules live in [`src/`](src/), workerd integration tests in
> [`test/`](test/), and D1 migrations will live in `migrations/`.

The entire backend as one deployable Worker (modular monolith, [ADR-0003](../../plan/adr/0003-modular-monolith.md)): `fetch`, `email`, `queue` and `scheduled` handlers, every Durable Object and Workflow class, serving the SPA, REST, MCP, OAuth, WebSockets and file transfer from one origin.

## Layout

| Path | What |
| --- | --- |
| [`wrangler.jsonc`](wrangler.jsonc) | Worker config: pinned compatibility date, `nodejs_compat`, observability, static assets with SPA fallback, and `run_worker_first` for every Worker-owned prefix |
| [`src/index.ts`](src/index.ts) | Composition root. Sends Worker-owned paths to the Hono app and everything else to static assets. Exports the `email`, `queue` and `scheduled` handlers |
| [`src/routes.ts`](src/routes.ts) | `WORKER_PREFIXES`, the paths the Worker owns ([architecture §3](../../plan/architecture.md#3-one-origin-request-routing)). Must match `run_worker_first`; `test/config.test.ts` enforces it |
| [`src/app.ts`](src/app.ts) | The Hono app: request ids, problem+json errors, routes |
| [`src/platform/`](src/platform/) | Cross-cutting runtime services, starting with HTTP plumbing |
| [`public/`](public/) | Placeholder page, until S00.T05 points assets at the `apps/web` build |
| [`worker-configuration.d.ts`](worker-configuration.d.ts) | Generated by `wrangler types`. Never edit it by hand |
| [`budgets.json`](budgets.json) | Bundle-size and startup-time budgets, checked by [`tools/budgets`](../../tools/budgets/) |

## Request handling today

- Paths under a Worker-owned prefix (`/api/`, `/mcp`, `/oauth/`, `/.well-known/`, `/auth/`, `/ws/`,
  `/blob/`, `/dl/`, `/hooks/`) go to the Hono app. Unknown ones get a `404` with an
  `application/problem+json` body, never the SPA.
- Every app response carries a server-generated `x-request-id`. A client-supplied one is ignored.
- `GET /api/v1/system/ping` returns `{ "ok": true }`. It is hand-written until the operation
  registry replaces it with `system.ping` (S00.T10).
- Any other path is served by static assets, which fall back to `index.html` for SPA routes.
  In production, browser navigations reach assets without running the Worker.
- `email` rejects inbound mail at SMTP time until the inbound pipeline exists (S04.T03), so senders
  get a bounce. `queue` acknowledges and logs. `scheduled` logs.

## Commands

Run these from the repository root.

```sh
pnpm test                                   # includes the workerd project ("dock")
pnpm --filter @soldock/dock dev             # wrangler dev
pnpm --filter @soldock/dock types           # regenerate worker-configuration.d.ts after editing wrangler.jsonc
pnpm types:check                            # fails if worker-configuration.d.ts is stale (CI)
pnpm budgets:check                          # builds with --dry-run, profiles startup, compares to budgets.json (CI)
```
