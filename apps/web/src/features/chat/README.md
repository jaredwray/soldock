# Message tools

Open **More message actions** on a message or a reply.

- Select **Pin to room** to keep the message in the room's pin list. Each member can see and remove a pin.
- Select **Save for later** to keep a private link. Open **Saved and reminders** in the sidebar to read or remove it.
- Select **Remind me** and choose a local date and time. The sidebar shows **Due** when a reminder is due. Dismiss it from **Reminders**.
- Select **Forward to room** and choose a destination. Its members can read the forwarded text. The source link requires access to the source room.

Select the clock beside **Send** to schedule a text message or a thread reply. Select **Pins and scheduled messages** in the room header to cancel a scheduled send. Attachments and replies that also go to the room use the usual send button.

## Drafts

The room composer and each reply composer have separate drafts. The browser saves each change locally and sends it with the last server revision. It checks the server on open, on focus, after a reconnect and every 30 seconds while visible.

When two devices change the same draft, select which copy to keep. Files stay on the device that selected them. Sign-out clears the local cache.

## Navigation

Press Command+K or Ctrl+K to switch rooms or people. Type part of a name or address. Use the arrow keys and press Enter to open a result.

Open **Activity** for mentions, replies, and reactions. Select an entry to open the message or reply. Use **Organize sidebar** to group rooms under a section name. Clear the section name to return a room to its default list.

Tab to a message list and use the arrow keys to move through messages. The **Keyboard shortcuts** button in the sidebar lists the available keys.


## Custom emoji

Open **Add a reaction** on a message. An organization owner or admin can select **Manage custom emoji** to upload a PNG.
Use up to 128 pixels per side and 32 KiB per file. Use the name between colons in a message, or select it from the reaction picker.
