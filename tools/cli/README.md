# `@soldock/cli` (`soldock`)

> Status: **planned**. Created by S00.T09 (`provision`); later commands arrive in S12.T16 (`restore`), S12.T08 (`dr rebuild`) and S14.T08 (`init`).

The operator CLI for self-hosters: provisions Cloudflare resources (D1, R2 buckets with lifecycle rules and bucket locks, KV, Queues and their DLQs, Email Routing, DNS), runs interactive setup, and (from S12) drives backup, restore and disaster-recovery operations through the authenticated admin API.
